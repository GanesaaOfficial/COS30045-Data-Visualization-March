Project Overview

Exercise 0.2: Foundations

A starting point for data visualization. This exercise introduces the essential components:

  • HTML page structure
  • CSS styling and layout
  • JavaScript interactivity
  • Basic data handling

Exercise 3: Advanced Story

A complete data storytelling project featuring:

  • Multi-page narrative structure
  • D3.js interactive charts
  • Dynamic navigation
  • Data-driven insights

Exercise 3 Pages

Navigate through multiple analytical perspectives:

  • Home: Overview & key statistics
  • Technology: Screen tech & sizes
  • Brands: Market overview
  • Power: Consumption analysis
  • Ratings: Energy star ratings
  • Conclusion: Key takeaways

Key Technologies

These projects demonstrate:

  • Semantic HTML5
  • Modern CSS design
  • ES6 JavaScript
  • D3.js (v7) visualization
  • CSV data loading
  • Responsive design
