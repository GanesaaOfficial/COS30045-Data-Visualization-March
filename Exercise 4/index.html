Exercise 4.1: SVG House & Garden

Static SVG

A coordinate mapping exercise comparing an initial AI-generated SVG with a manually refined version.

1. Original AI-Generated SVG

👁️ View AI SVG Code 
<svg viewBox="0 0 600 400">
    <rect x="0" y="0" width="600" height="300" fill="#87CEEB" />
    <rect x="0" y="300" width="600" height="100" fill="#228B22" />
    <rect x="200" y="150" width="200" height="150" fill="#F5DEB3" />
    <polygon points="180,150 300,50 420,150" fill="#A52A2A" />
    <rect x="280" y="220" width="40" height="80" fill="#8B4513" />
    <rect x="220" y="170" width="35" height="35" fill="#ADD8E6" />

2. Manually Modified SVG

👁️ View Modified SVG Code 
<svg viewBox="0 0 600 400">
    <rect x="0" y="0" width="600" height="300" fill="#bae1ff" />
    <rect x="0" y="300" width="600" height="100" fill="#baffc9" />
    <path d="M 270 300 L 220 400 L 380 400 L 330 300 Z" fill="#d3d3d3" stroke="#aaaaaa" />
    <rect x="230" y="90" width="30" height="60" fill="#964b00" stroke="#5c2e00" />
    <rect x="200" y="150" width="200" height="150" fill="#ffdfba" stroke="#e0b88d" stroke-width="2" />
    <polygon points="200,150 300,70 400,150" fill="#ffb3ba" stroke="#d98890" stroke-width="2" />
    <rect x="280" y="220" width="40" height="80" fill="#bcd4e6" />
    <circle cx="310" cy="260" r="4" fill="#ffd700" />
    <g class="windows" fill="#ffffba" stroke="#d0d08a" stroke-width="2">
        <rect x="220" y="170" width="35" height="35" />
        <rect x="345" y="170" width="35" height="35" />
    </g>
</svg>

Manual Modifications Applied:

  • Styling & Colors: Swapped harsh default colors for a softer pastel palette and added stroke outlines.
  • New Elements: Manually added a chimney (<rect>), a driveway (<path>), and a doorknob (<circle>).
  • Grouping: Wrapped the windows in a <g> tag to apply fill and stroke styles uniformly.
  • Typography: Added a <text> element at the top to serve as a label.
